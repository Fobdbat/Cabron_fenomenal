# Fenomenal (Cabron & DJ CW): joc musical

## Què cal pujar al repositori nou
Puja **tots aquests fitxers a l'arrel** del repositori (Add file → Upload files):

- `index.html`
- `joc.js`
- `nivell.js`
- `three.min.js`
- `coperta.jpg`
- `medalio.jpg`
- `fenomenal.mp3`
- `manifest.webmanifest`
- `icona-180.png`
- `icona-192.png`
- `icona-512.png`

Aquest `LLEGEIX-ME.md` no cal pujar-lo.

## La lletra (`versuri.txt`)
El joc llegeix la lletra d'un fitxer `versuri.txt` que ha d'estar al repositori. No va dins del paquet.

1. Al repositori: **Add file → Create new file**.
2. Posa-li de nom `versuri.txt`.
3. Enganxa-hi la lletra **tal com me la vas passar**: una línia per vers, 50 versos. Les línies en blanc entre blocs no compten.
4. **Commit changes**.

Els moments de cada vers estan calculats per a aquests 50 versos. Si canvies el nombre de línies, o les que diuen «lup» i «fenomenal», el joc torna a un càlcul automàtic menys precís.

Si no hi ha `versuri.txt`, el joc funciona igual però sense lletra.

## Publicar-lo (GitHub Pages)
Settings → Pages → Branch: `main` / `(root)` → Save.

L'adreça serà `https://fobdbat.github.io/<nom-del-repositori>/`.
